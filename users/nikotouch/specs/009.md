
# 009 Artsey入力対応

## 概要
５６式ポケベル入力をテンキーのキーボードである Q0 Maxに実装した
しかし、ポケベル入力でのアルファベット入力はかなり入力しずらい
そこで、Artsey入力方式に対応して、片手で日本語も、英語も入力できるようにする

## 方針
- Artsey入力方式はテンキーのみに必要なので、AL68といった60%以上のキーボードには実装しなくていよい
- Artsey入力の対応には、5つのレイヤーを追加する必要がある
 そのため、現在使用中の4レイヤーに加えて5レイヤーを追加するので、レイヤー定義としては、9レイヤーとする
- 既存の５６式ポケベル入力実装には何も変更を加えない
 変更が必要なことについては必ず設計者の了解を得ること

## レイヤー操作
### レイヤー定義
- NT_BASE
- NT_FN
- NT_NIKOTOUCH
- NT_NIKOSHIFT
- NT_ARTSEY_ALPHA
 Artsey入力の基本部分のレイヤー
- NT_ARTSEY_KAKO
 Artsey入力の括弧のレイヤー
- NT_ARTSEY_SYMBOL1
- NT_ARTSEY_SYMBOL2
- NT_ARTSEY_SYMBOL3
 Artsey入力の記号用レイヤー
 
### レイヤー切り替え（常時有効）
- M1: [BASE]レイヤーに切り替え
- M2: [NIKOTOUCH]レイヤーに切り替え
- M3: [ARTSEY_ALPHA]レイヤーに切り替え

### ARTSEYのレイヤー切り替え
ARTSEY_ALPHAレイヤーにおいて
- 1キーを押している間は ARTSEY_KAKO レイヤーに切り替え
- 4キーを押している間は ARTSEY_SYMBOL1 レイヤーに切り替え
- -キーを押している間は ARTSEY_SYMBOL2 レイヤーに切り替え
- Entキーを押している間は ARTSEY_SYMBOL3 レイヤーに切り替え
- .キーを押している間は NIKOSHIFT レイヤーに切り替え

## Artsey入力対応表
- コンボ入力時の変換も含めたArtseyキー入力表は、ARTSEY.csv に定義した
- 各レイヤーヘッダーを確認して変換を確認すること
- 列の意味（複数の記載がある場合は、コンボ入力を意味する）
  - 1列目: 1つめの入力キー
  - 2列目: 2つ目の入力キー
  - 3列目: 3つ目の入力キー
  - 4列目: 4つ目の入力キー
  - 5列目: 送信するコード
    N/Aの場合は何も送信しないこと

## 確認事項

### Q1: M1キーの動作確認
M1は「BASEレイヤーに切り替え + kana送信（日本語入力ON）」とありますが、
現在のnikotouch実装では M1 = 「BASEレイヤー + 英数（日本語OFF）」、M2 = 「NIKOTOUCHレイヤー + かな」です。
- [ ] M1 = BASE + かな（日本語ON）、M2 = NIKOTOUCH + かな に変更する
- [O] 記載ミス。現在の動作（M1 = BASE + 英数、M2 = NIKOTOUCH + かな）を維持する

### Q2: M3キーの現在の動作
現在 M3 は未割り当てです。ARTSEY_ALPHAレイヤー切り替えに変更してよいですか？
- [O] はい、M3 = ARTSEY_ALPHA に変更する
- [ ] いいえ、別のキーを使用する（指定: ______）

### Q3: Artseyのコンボ検出時間
Artseyのコンボ入力（2〜4キー同時押し）の検出時間は？
- [O] 50ms（現在のCOMBO_TERM_56と同じ）
- [ ] 30ms（より高速な入力向け）
- [ ] その他: ___ms

 コンボ検出時間は、56コンボと合わせて、ソースコード前方に定数定義があると良い
 既にあるのなら、それを使う

### Q4: レイヤーホールド中の他キー入力
1キーを押してARTSEY_KAKOレイヤーに切り替え中に、他のキーを押した場合は？
- [O] KAKOレイヤーのキーとして処理する（1キー自体は無視）
- [ ] 1キー離した時点でKAKOレイヤー解除、その後のキー入力はALPHAレイヤーとして処理

### Q5: 実装範囲
今回の実装で対応する範囲を確認：
- [O] Q0 Maxのみ（AL68は変更なし）
- [ ] Q0 MaxとAL68の両方（AL68にもレイヤー定義を追加）

### Q6: nikotouch.h/cへの変更
既存の56式ポケベル入力実装への変更について：
- [O] nikotouch.hのレイヤー定義（NT_LAYER_COUNT）を8に拡張する
- [ ] nikotouch.h/cには変更を加えず、Q0 Maxのkeymap.cで独自にレイヤーを追加する

 実装は、artkey.c のように、nikotouch.c には変更を加えないで、
 別ソースファイルに作成できると良い
 
 自作キーボードで使うロジックにもなるので、
 Q0 Maxだけで動くような配置にはしたくない
