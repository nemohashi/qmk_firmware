## 改善仕様
- ロールオーバー入力対応
 素早く文字を入力する際に、例えば、a, r と文字を打つには、
 1キー、2キーと連続で入力するが、
 1キーを完全に離す前に、2キーを押しても、a, rと文字を打てるようにする。
- .ｋキーのシフトに対応して矢印入力できるようにする
 NT_NIKOTOUCHレイヤーで有効な、MO(NT_NIKOSHIFT)  を、
 NT_ARTSEY_ALPHAレイヤーでも使えるようにする
 
### ARTSEY.csv 変換表修正の対応
- backspaceコンボの実装
- deleteがBSになってるので直す
- esc、tabの実装
- 7キーをbackspaceにする
- ent2はenterにする

### Shiftコンボの実装
- Once Shift
 4, 2, 3, - キーのコンボで、Once Shiftを有効にする
 次に入力したアルファベット文字を大文字にして送信する

- トグルShift
 1, 5, 6, Entのコンボで、トグルShiftを有効にする
 解除も同じコンボ
 トグルShiftが有効中は、アルファベットの入力を大文字にして送信する

### 4. Shiftコンボの動作詳細

**Once Shift (4+2+3+- コンボ)**
- 次の1文字のみ大文字化する
- 対象キー：
  - [O] アルファベットのみ（a-z）
  - [ ] 記号も含む（例: ! → shift+1）
- 大文字化後の状態：
  - [O] 自動的にOnce Shiftは解除される
  - [ ] 手動で解除が必要

**トグルShift (1+5+6+Ent コンボ)**
- ON/OFF切り替え式
- 対象キー：
  - [O] アルファベットのみ（a-z）
  - [ ] 記号も含む
- トグル状態の表示：
  - [ ] LED等で状態表示が欲しい
  - [O] 不要
- トグルShiftとOnce Shiftの関係：
  - [O] トグルShiftがONの時、Once Shiftは無視される
  - [ ] 併用可能（Once Shiftで一時的に小文字）
