
# 008 ポケベル入力の高速入力対応 その２

## 対応仕様
- ロールオーバー入力対応
 今は「う」を入力するとき、明確に、1, 3 とキーを押さなければならないが、
 1キーを離す前に、3を押しても、「う」を入力できるようにする。
 すべてのキーの組み合わせで、このロールオーバー対応を行う。

## 確認事項

### Q1: 1-5キーの長押し機能との併用
007で実装した1-5キーの長押し（160ms）機能との関係は？
- [O] ロールオーバー優先（1を押して160ms以内に3を押せば「う」、3を押さずに160ms経過で「あ」）
- [ ] 長押し無効化（ロールオーバー実装に伴い、1-5キーの長押し機能を削除する）

### Q2: 3キー以上の連続入力
1を押したまま3を押し、さらに3を離さずに5を押した場合は？
- [O] 「う」のみ（最初の2キーで確定、5は次の1キー目になる）
- [ ] 「う」→「の」（1+3で「う」確定後、5の長押し扱いで「の」も出力）

### Q3: 同じキーの連続押し
1を押したまま、もう一度1を押した場合（1+1のロールオーバー）は？
- [O] 「あ」を出力する（1+1 = 「あ」として処理）
- [ ] 無視する（同じキーの重複押しは処理しない）
