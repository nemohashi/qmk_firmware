
# qwertyレイアウトでの56式ポケベル入力対応

## 対応方針
- 右手ホームポジションに最適化してポケベル入力に対応する
- テンキーでの#キー押しで矢印入力は不要（矢印キーはあるはずなので）
- Cir, Tri, Sqr, Crsボタンの割当は不要
- M1, M2, M3, M4, M5の割当は不要

## レイヤー切り替えとDFUモード
- 下記は56式ポケベル入力のキー定義ではなく、キーボード本来のキーで指定
- Fn + KC_DELETE で56式ポケベル入力レイヤーに切り替えられるようにする
- Fn + KC_PAGE_UP で切り替える前のレイヤーに戻れるようにする
- Esc で切り替える前のレイヤーに戻れるようにする 

## 対応キー仕様
キー定義: 実キー で下記を仕様とする

```
1: 7
2: 8
3: 9
-: 0
4: u
5: i
6: o
Ent: p, ;
7: j
8: k
9: l
*: n
0: m
#: ,
Ent2: .
Space: Space
```

## 無効にしないキー
- 下記は56式ポケベル入力のキー定義ではなく、キーボード本来のキーで指定
- そのまま有効にするキー（透過設定にする）
  - Backspace
  - Enter
  - 矢印キー（上下左右）
  - Shift（左右ともに）
- レイヤー切り替えに使うキー

### Q3: 56式コンボ機能（5+6→*, 4+5→0）

### Q4: レイヤー切り替えの動作
「Fn + 5」と「Fn + \」でNIKOTOUCHレイヤーに入る際：

- [ ] トグル動作（押すたびに切り替え）
