## 基本仕様

### キー配列
- **キー数**: 14キー（ミニマル版）
- **レイアウト**: カスタム配列（テンキーベース・簡略版）
- **分割型**: No（一体型）
- **マトリックス**: 5行 x 5列（14キー実装、11キー予約）
- **詳細**: `docs/specs/001.md` 参照

#### キー配列図（ミニマル版）

### 物理的な仕様
- **キースイッチ**: Cherry MX互換
  - ホットスワップ対応（Kailh PCBソケット CPG151101S11）
- **キーキャップ**: Cherry プロファイル
- **プレート素材**: アクリル（サンドイッチ構造）※後日実装
- **ケース**: アクリルサンドイッチケース※後日実装

### 電子部品
- **マイコン**: Pro Micro / BLE Micro Pro（Pro Micro互換、選択可能）
  - Pro Micro: 有線USB接続、QMK対応
  - BLE Micro Pro: 無線BLE + USB、QMKベースファームウェア
  - コンスルー 12ピン接続（取り外し可能）
- **ダイオード**: 1N4148W（表面実装型 SOD-123） x 14個
- **USB接続**: USB Type-C（マイコンに内蔵）
- **バッテリー**: LiPo 3.7V 150-300mAh（BLE Micro Pro使用時のみ）
  - JST PH 2.0mm 2ピンコネクタ（B2B-PH-K）で接続
  - 推奨: LP401235（150mAh）または遊舎工房400mAh電池
- **RGB LED**: No（シンプル版のため）
- **バックライト LED**: No
- **OLEDディスプレイ**: No
- **ロータリーエンコーダー**: No
- **リセットスイッチ**: キーマップで実装（QK_BOOTキー）

└──────┴──────────────┴──────────────┘

#### マトリックス構成
- **行（ROW）**: 5行（ROW0～ROW4）
- **列（COL）**: 5列（COL0～COL4）
- **実装キー数**: 14キー（予約11キー分の配線あり）

#### QMK config.h用定義
```c
// Row pins (Pro Micro pin number -> AVR pin name)
#define MATRIX_ROW_PINS { D1, B3, D4, B6, B2 }

// Column pins  
#define MATRIX_COL_PINS { C6, D7, E6, B4, B5 }

// Diode direction (COL2ROW or ROW2COL)
#define DIODE_DIRECTION COL2ROW
```

**注**: BLE Micro Pro使用時もPro Microと同じピン配置で動作します。

### 機能仕様
- **ホットスワップ対応**: Yes - Kailh PCBソケット使用
- **QMK対応**: Yes
  - Pro Micro使用時: QMK Firmware
  - BLE Micro Pro使用時: QMKベースファームウェア（JSON/Vial設定）
  - 56式ポケベル入力実装を移植
  - Artsey入力実装を移植
  - Combo入力対応
- **無線対応**: 選択可能
  - Pro Micro: 有線のみ
  - BLE Micro Pro: BLE無線 + 有線（切替可能）
- **トラックボール/ポインティングデバイス**: No

## 設計目標・コンセプト
（ここに、このキーボードで実現したいこと、使用目的、デザインの方向性などを記載）
- 片手で日本語、英語、数値を入力できるキーボードを製作する
- 日本語は56式ポケベル入力を採用する
 56式というのは、濁点等の変換に56をコンボ入力することで行えるようにした、私独自の入力方式である
- アルファベットや記号は、Artsey入力方式を採用する（すでにテンキー向けの実装あり）
- シンプルな片手入力用キーボードで、リラックスしながら文字を打つことができるものにする
