
# 007 ポケベル入力の高速入力対応

## 対応仕様
- 4と5を同時に押すと、0を押したときと同じにする仕様は、
  6と7の同時押しに変更する。
- 「あ」、「き」、「す」、「て」、「の」 長押し入力に対応する
 つまり、11と入力すると、"a", 22と入力すると"き" であるが、
 1の長押しで"a", 2の長押しで "ki" と送信する
 3の長押し "su"
 4の長押し "te"
 5の長押し "no"
 
## 確認事項

### Q1: 長押しの判定時間
長押しと判定するまでの時間は何ミリ秒にしますか？
- [ ] 150ms
- [ ] 200ms
- [ ] 250ms
- [ ] その他: 160ms

### Q2: 長押し中の表示
1を長押し中、子音「あ行」を表示しますか？
- [ ] 表示する（従来通り「あ行」→長押し完了で「あ」に変わる）
- [O] 表示しない（長押し完了まで何も表示しない）

### Q3: 長押し後の連続入力
1を長押しして「あ」が出た後、続けて2を長押しすると？
- [O] 「あき」になる（連続長押しで文字を追加）
- [ ] 「き」になる（新しい文字で上書き）

### Q4: 長押し中にキーを離した場合
1を押して100ms後（判定時間未満）に離した場合は？
- [O] 「あ行」を表示（従来の1キー押下と同じ動作）
- [ ] 何も表示しない

### Q5: 4+5コンボの扱い
既存の4+5=0キーのコンボを削除しますか？
- [O] 削除する（6+7のみ0キーになる）
- [ ] 残す（4+5と6+7の両方が0キーになる）
