## 将来的な展望
今は実装しなくてもよいが、設計上考慮する必要があれば、下記の拡張予定を考慮ください
- テンキー版を作成予定
 テンキー版はガラケーのボタンと同じで、mini版では省略した、*, # キーがある また、÷、×、‐、.、+ 等の算術記号のキーもある
- BLE Micro Proを使った無線対応版のファームウェアも作成予定
 これはQMK firmwareベースだが、かなり異なるようなので、最初はまず、QMK firmwareのソースにも取り込まれているらしい、Micro Proのみを対象とする
 
 
## 対応仕様 ファームウェア的に必要と思われること
- Fn + Bs キーによって、QK_BOOTを定義する
 つまり、FnレイヤーのBsをQK_BOOTにする

## 対応仕様 keymap.cを作る上で必要と思われること
### Q0 Maxで開発したときのキー定義表 

下記により、キー配置と、独自キー名を定義する
```
┌──────┬──────┬──────┬──────┬──────┐
│ Renc │ Cir  │ Tri  │ Sqr  │ Crs  │
├──────┼──────┼──────┼──────┼──────┤
│ M1   │ 1    │ 2    │ 3    │ -    │
├──────┼──────┼──────┼──────┼──────┤
│ M2   │ 4    │ 5    │ 6    │ Ent  │
├──────┼──────┼──────┼──────┼──────┤
│ M3   │ 7    │ 8    │ 9    │      │
├──────┼──────┼──────┼──────┼──────┤
│ M4   │ *    │ 0    │ #    │ Ent2 │
├──────┼──────┴──────┼──────┼──────┤
│ M5   │    Space    │ .    │      │
└──────┴─────────────┴──────┴──────┘
```

### キー配列図（mini版）
```
┌──────┬──────┬──────┬──────┐
│      │      │      │  Fn  │
├──────┼──────┼──────┼──────┤
│  1   │  2   │  3   │  BS  │
├──────┼──────┼──────┼──────┤
│  4   │  5   │  6   │      │
├──────┼──────┼──────┤ Ent  │
│  7   │  8   │  9   │      │
├──────┴──────┼──────┴──────┤
│    Space    │      0      │
└─────────────┴─────────────┘
```

### キー定義の対応
- Q0 Maxの*, 0, # キーはないものとして扱う
- Q0 Maxの.キーの動作を、mini版の0キーが担う
 ただし、Baseレイヤーの0を打つには、0キーを使う
- 算術記号を打つには、Fnレイヤーに記載予定
- Q0 Maxの-キーの動作を、mini版のBsキーが担う
- Q0 MaxにはEnt,Ent2があるが、mini版ではEntが一つしかない
 そのため、EntとEnt2の動作をmini版のEntが担う
 1つのEntで問題がある場合は、このmd作成時に要相談
