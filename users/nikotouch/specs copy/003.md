
# ユーザーフィードバック対応1

## . + Enter でシフト＋エンターを送信できるようにする
- .キーでNIKOSHIFTレイヤーに対応しているが、.キーを押しながらEnterキーを押したときは、Shift修飾付きのEnterが送信されるようにする

## やゆよは母音を他と合わせた変換に変更する
- 修正した変換表を NIKOTOUCH.csv に置くので対応する
- 変更点はやゆよ行を他のキーと母音の位置を合わせること　空いたキーに小文字のゃゅょを割り当てる
　また、やゆよにはそれぞれ*キーを有効にして、小文字に変更できるようにする

## *キーとしてM5キーを使えるようにする
- M5キーは現在MO(FN)として動作するようにしているが、その役割はM4キーに変更する
- M5キーは*キーとして使えるようにする
　これは親指で濁点などの変換をできるようにするためである

### Q1: やゆよ行の変換表について



これは正しいですか？疑問点：
- [ ] 8+2 が "lya" になっていますが、これは "i" の位置なので意図通りですか？
- [ ] 8+4 も "lya" になっていますが、これは "e" の位置です。意図通りですか？

```
8,1,___,___,  (aの位置)

8,3,___,___,  (uの位置)
8,4,___,___,  (eの位置)
8,5,___,___,  (oの位置)
```
